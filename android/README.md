# Akawo — Native Android App

A fully native (non-webview) Android client for the [Akawo](..) Nigerian savings
and contribution platform. It speaks to the same Cloudflare Worker backend
(D1 + R2 + KV) that the web frontend uses, via the REST API documented in
`docs/API.md`.

**Kotlin + Jetpack Compose + Hilt + Retrofit + OkHttp.** Not a React Native
webview — every screen is native Compose, media is captured through the camera
and gallery intents, and tokens are stored in EncryptedSharedPreferences
(Android Keystore).

> ⚠️ Build note: this sandbox has no Java/Android SDK, so the project cannot be
> compiled here. Open `android/` in **Android Studio** (Hedgehog or newer) and
> let it sync/download the Gradle wrapper and Android SDK. The Gradle wrapper
> JAR is intentionally not committed — Android Studio regenerates it on first
> sync, or run `gradle wrapper` (Gradle 8.2) once Gradle is installed.

## Features (everything from the API)

- **Auth**: register (name, email, password, 11-digit BVN), login, session
  restore, forgot/reset password, email verification (deep links), logout with
  refresh-token rotation.
- **Dashboard**: NGN totals, pending/monthly commitments, next contribution
  (overdue flagging), recent contributions & payments, KYC/email status, admin
  shortcut.
- **Contributions**: create (₦1–₦10,000,000, due date, label, once/monthly),
  list with label + status filters + pagination, edit, delete (guarded against
  in-flight payments).
- **Payments**: pay by card (mock gateway: test cards succeed/`…002` insufficient
  funds/`…003` blocked) or upload bank-transfer proof (image/PDF); monthly
  recurrence auto-schedules the next installment.
- **Identity (KYC)**: facial photo + liveness video capture via camera/gallery,
  submission status, history, reject-reason, view your own signed media.
- **Profile**: name/phone/email (read-only), change password (signs out all
  devices).
- **Notifications**: in-app inbox, unread count, mark read / mark all read.
- **History**: paginated payment history with contribution labels.
- **Admin console** (role-gated): stats, users (suspend/activate,
  promote/demote with last-admin & self guards), KYC queue (approve/reject with
  reason, view face + liveness media), payments (approve/reject proof), email
  outbox, audit log.

## Configure the API base URL

The app targets a local Worker by default so you can run `wrangler dev` and
point the emulator at it:

`android/app/build.gradle.kts`:
```kotlin
buildConfigField("String", "API_BASE_URL", "\"http://10.0.2.2:8787\"")
```

`10.0.2.2` is the Android emulator's alias for `localhost`. For a production
Worker, change it to `https://akawo-api.<account>.workers.dev` (HTTPS is
required on production — cleartext is only permitted for `10.0.2.2`/`localhost`
via `network_security_config.xml`).

Local dev run:
1. In `worker/`: `npm run dev` (D1/R2/KV run locally; schema self-bootstraps).
2. `npm run db:seed` (demo users: `admin@akawo.dev` / `chinedu@akawo.dev` /
   `amina@akawo.dev` / `tunde@akawo.dev`, password `Akawo#Demo1`; admin
   `Akawo#Admin1`).
3. Open `android/` in Android Studio → sync → run on an emulator (API level 24+).

## Signing

- Debug: Android Studio's default debug keystore is used automatically.
- Release: create `android/keystore/release.keystore` (keytool) and set Gradle
  properties in `~/.gradle/gradle.properties`:
  ```
  AKAWO_RELEASE_STORE_FILE=/path/to/release.keystore
  AKAWO_RELEASE_STORE_PASSWORD=...
  AKAWO_RELEASE_KEY_ALIAS=akawo
  AKAWO_RELEASE_KEY_PASSWORD=...
  ```

## Native capabilities deliberately included

- **Camera/gallery media capture** for KYC facial photo, liveness video, and
  transfer-proof uploads (not file inputs — real Android intents).
- **Encrypted token storage** (refresh token in Keystore-backed
  EncryptedSharedPreferences; access token in memory), with transparent OkHttp
  refresh-token rotation on 401.
- **NGN formatting** using the `en-NG` locale (₦1,250,000.00) and compact
  (₦1.2m) variants; dates formatted in Africa/Lagos.
- **Accessibility**: content descriptions, TalkBack-friendly fields, reduced
  motion awareness, dark theme.
- **Deep links**: `akawo://verify?token=…` and `akawo://reset?token=…` for
  email magic links.
- **WorkManager-ready** reminder hook (server cron sends due-date reminders; the
  app can schedule local alarms on top).

## Testing

Local unit tests (JUnit + Robolectric) can be added under
`app/src/test/` — they run on the JVM and do not require an emulator or the
Android SDK beyond the Robolectric dependency already declared.

Instrumented UI tests would go under `app/src/androidTest/` and need an
emulator/device.
